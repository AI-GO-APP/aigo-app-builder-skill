# aigo-learning 0.1.1：PDF 教材與統一學生手冊

## 變更

- 學生閱讀材料改為一份六頁 A4 PDF：安裝與個人設定、第一個練習、成果輸出、三頁六階段學習計畫。
- 對學生的說明不另拆多份 Markdown；JSON 來源供教師維護。技能仍以獨立 ZIP 安裝。
- 學生技能按需產生 PDF 教材、作業單、驗收紀錄及操作說明；保留來源，檔案放工作區，不操作 AI GO。
- 增加可選本機產生器與隔離相依清單。以實際字型檢查缺字、文字擷取與 A4／頁數驗證；渲染成功仍標人工版面待確認。
- 原有一般版入口、工具、VERSION 及 74 檔位元保持不變；一般版 zip SHA-256 與 0.1.0 時一致。

## 實際驗證

使用本機 bundled Python，reportlab 4.4.9、pypdf 6.10.0，系統微軟正黑體與 Poppler。

`python -X utf8 -m unittest discover -s tests -p 'test_learning*.py' -v`：35 項全部通過。
其中 24 項為先前套件／scope 回歸，11 項新增涵蓋 PDF schema、產物實際文字、A4、頁數限制、
不覆蓋舊檔、不寫技能目錄、缺字型／缺渲染器與部分成功狀態，以及實際 PNG 渲染。

手冊實際六頁 A4，逐頁有可擷取文字；pdfplumber 查無超出頁面的字元。
六頁均以 pdftoppm 渲染，主代理逐頁目視確認中文字、表格、頁尾、段落與邊界，無可見裁切、方框字或重疊。
打包完整性與 skill-creator quick_validate 通過；安裝包包含輸出指引、PDF 產生器及相依清單。

另以未繼承主工作對話的獨立代理 learning_pdf_forward_test，從最終安裝包接收學員題目：
「缺聯絡日期不等於零逾期」，要求兩頁以內 PDF、例子、練習與驗收標準及可編輯來源。
實際完成兩頁 A4 繁體 PDF 與 JSON，使用包內工具產生及渲染；獨立核對文字、字型嵌入與兩頁版面，
全程離線、只寫指定練習工作區，沒有登入或操作 AI GO。教材的真實平台行為與學員理解未冒稱已驗證。
